# Code of conduct

Be kind, assume good faith, and keep it about the code.

- **Mod authors are not suspects.** A flagged mod is a question, not an accusation. Don't name, shame or pile on
  anyone over a WorkshopGuard verdict, here or anywhere else.
- **No harassment**, insults, or personal attacks, and no posting anyone's private information.
- **No malware.** Don't share working malware, links to download it, or help making it. Hashes and descriptions are
  fine.

Breaking these gets a comment deleted, then a ban from the repo. To report something, use the
[private report](SECURITY.md) or email the maintainer through their GitHub profile.
