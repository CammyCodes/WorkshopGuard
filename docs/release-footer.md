
**Get it**

- Scanner: `docker pull ghcr.io/cammycodes/workshopguard:latest`, then the [quick start](https://github.com/CammyCodes/WorkshopGuard#quick-start).
- Launch gate (Windows): download the source zip below, then `scripts\install-gate.ps1` ([how](https://github.com/CammyCodes/WorkshopGuard/blob/main/docs/GATE.md)).
- ModGuard for your game: `dotnet add package WorkshopGuard.ModGuard`, or `WorkshopGuard.ModGuard.dll` below for Unity's `Assets/Plugins` ([guide](https://github.com/CammyCodes/WorkshopGuard/tree/main/modguard)).

No scanner catches everything: read [what it can't do](https://github.com/CammyCodes/WorkshopGuard#what-it-cant-do). Found malware it missed, or a false alarm? See [SECURITY.md](https://github.com/CammyCodes/WorkshopGuard/blob/main/SECURITY.md).
